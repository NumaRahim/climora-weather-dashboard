# 🌤️ Climora – Modern Weather Dashboard

A modern, responsive weather dashboard built with **HTML, CSS, and JavaScript** that provides real-time weather information, detailed air quality insights, and a 7-day weather forecast using the **WeatherAPI**.

Designed with a clean glassmorphism-inspired interface, Climora delivers an intuitive experience for exploring current weather conditions and upcoming forecasts.

---

## ✨ Features

- 🌍 Search weather by city name
- 🌡️ Real-time temperature and weather conditions
- 📅 7-day weather forecast
- 💧 Humidity information
- 🌬️ Wind speed and wind direction
- 👀 Visibility data
- 🤒 Feels Like temperature
- 📍 Latitude and Longitude
- 🕒 Local time based on searched location
- 🌫️ Air Quality Index (AQI)
- 🧪 Air pollution metrics:
  - CO (Carbon Monoxide)
  - NO₂ (Nitrogen Dioxide)
  - O₃ (Ozone)
  - SO₂ (Sulfur Dioxide)
  - PM2.5
  - PM10

- 🔄 Refresh weather data
- 🌙 Modern responsive dashboard UI

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/your-username/climora-weather-dashboard.git
```

### Navigate to the project

```bash
cd climora-weather-dashboard
```

### Open the project

Simply open `index.html` in your browser or use **Live Server** in Visual Studio Code.

---

## 🔑 API

This project uses **WeatherAPI** to retrieve weather and air quality data.

You'll need your own API key.

Replace the API key in the JavaScript file with your own key.

> **Note:** This project is a frontend-only application. API keys included in frontend applications are visible to users. For production deployments, use a backend server (such as Node.js/Express) to securely store API credentials.
